# Models, datasets and licenses

Policy: everything that runs at request time is Apache-2.0, MIT or BSD. Anything under another
license is used only offline (evaluation or comparison), never by the running stack. The pinned
revision, file hashes and license of every model live in `infra/models.lock.json`, which
`make models` resolves against the Hugging Face Hub; this page is the readable summary.

## Datasets

| Dataset | Use | License |
|---|---|---|
| UAE synthetic invoices (`factory/`) | Training, calibration and test splits | Generated by this repo; same license as the code |
| DocILE | External extraction evaluation (not run in v1.0: needs an access token) | Research use under the DocILE terms (docile.rossum.ai) |
| FATURA | Extractor B training mix; its test split was not evaluated in v1.0 | CC-BY-4.0 |
| ExtractBench | External extraction evaluation | Apache-2.0 |
| CORD v2 (`naver-clova-ix/cord-v2`) | Extractor B training (train split) and real-data evaluation (test split) | CC-BY-4.0; receipts from NAVER Clova AI |
| deepset/prompt-injections | Training and testing the injection guard | Apache-2.0 |
| AgentDojo | Agent prompt-injection evaluation | MIT |
| PINT AE 1.0.4 schematron and code lists | E-invoice validation | OpenPeppol release, used unmodified; fetched and hash-pinned by `python -m evals.pint_ae.fetch` |

Datasets are fetched by `python -m evals.datasets` into `data/`, which is never committed. Each
download is recorded with its sha256 in `data/manifest.json`.
